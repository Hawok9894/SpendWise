
# SpendWise - Budget Tracker

## Project Description
SpendWise is a simple budget tracking application built using HTML, CSS, and JavaScript. It helps users manage their budgets, track expenses, calculate spending, and check their remaining balance.

## JavaScript Concepts Implemented

### 1. Variables
Variables are used to store the total budget, expenses, and remaining balance.

### 2. Data Types
Numbers are used to store budget and expense values.

### 3. User Input
The prompt() function collects the user's budget and expenses.

### 4. Budget Calculations
JavaScript calculates the remaining balance by subtracting total expenses from the total budget.

### 5. Functions
The calculateBalance() function performs budget calculations and makes the code reusable.

### 6. Console Output
console.log() displays the budget summary and calculated results in the browser console.
